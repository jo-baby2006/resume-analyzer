#  AI Resume Analyzer

An AI-powered app that analyzes your resume like a senior hiring manager and gives instant honest feedback.

## What it does
-  Upload any resume (PDF)
-  AI reads it and gives feedback
-  Shows what's strong
-  Shows what's weak
-  Shows what's missing
-  Suggests top 3 improvements

## Built With
- Python
- PyPDF2
- Groq LLM API
- Streamlit
